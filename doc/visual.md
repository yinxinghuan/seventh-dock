# 《Seventh Dock》视觉圣经

## 1. 视觉命题

- 方向：A2「对话世界志」。
- 一句话：一本在风暴前持续写下去的港区现场通讯录。
- 核心情绪：潮水逼近，但每个同行者仍会记得玩家如何做出选择。
- 标志瞬间：关键回复后原位出现“正在记录现场”，随后显影为带主角身份的 4:3 港区场景图。
- 避免：调试仪表盘、海盗主题装饰堆砌、圆角卡片墙、图片回写页面顶部。

## 2. 构图与视角

- 响应式竖屏 DOM；390×844 与 320×568 主验收，桌面 Shell 最大 720 px，正文最大 610 px。
- 顶部 84–104 px：标题、港区/时间、潮位/补给/警戒、44 px `Aa` 文字设置和 World 按钮。
- 中部：独立滚动时间线，按发生顺序混排玩家行动、叙述、台词、检定、变化和图片。
- 底部 104–152 px：横向快速回复与自由输入；选项按文字量形成 148–310 px 的长短节奏，并以露出下一项暗示可滑动。
- 玩家消息靠右，32 px 头像固定在外缘；NPC 消息靠左。World 抽屉覆盖时间线而不永久占位。

## 3. 色彩

- 深港 `#0C1A1D`、雾纸 `#D7D8CB`、潮绿 `#3D7C82`、锈橙 `#B6603C`、灯金 `#D3A653`、墨色 `#1E2929`。
- 正文对比至少 4.5:1；危险、成功与关系变化同时依靠文字/结构，不只换颜色。
- 不使用霓虹、玻璃、通用紫蓝渐变。

## 4. 字体

- 叙述：`Songti SC, Noto Serif SC, Georgia, serif`，小/标准/大为 16/17/19 px，行高 1.75。
- 台词与行动：`Inter, PingFang SC, Noto Sans SC, sans-serif`，小/标准/大为 14/15/17 px，行高 1.5。
- 地点、数值与记录：等宽风格 9–12 px。
- 英文标题使用 Georgia/Iowan Old Style，短标题允许 Title Case；中文标题不使用全大写式字距。
- `Aa` 打开三档紧凑菜单；当前档同时用描边、底色和 `aria-pressed` 表达。选择写入 `localStorage.alteru_story_text_size`，不进入故事存档。

## 5. 形状、材质与光线

- 直边页面、1 px 分隔线、4 px 以内微圆角；材质来自受潮纸、帆布书脊和氧化金属索引。
- 场景图平视或轻俯视，雨后冷天光与灯笼暖光形成双温度；阴影只表达纸页层级。
- 入口使用独立的 16:9 暴雨外港横图：三名旅人、唯一潮钟、灯与旧海图均位于中央安全区；画面全出血，不带画框、纸边、留白或文字。生成占位继续使用方形世界母图的低饱和、低明度和扫描线处理。

## 6. 角色、环境与资产

- 当前 AlterU 用户是主角；头像用于玩家消息、人物页，并在关键剧情图中作为人物参考。
- 生图保持主角可辨识脸部，但服装、姿态、雨光和镜头服从港区世界；环境与事件仍是主体，禁止自拍式大头照。
- 固定环境元素：雨后外港、潮尺、旧海图、石墙、灯笼与远处同行者。图像无 UI、Logo、可读伪文字。
- 正式海报为 Aigram transit 生成的 1024×1024 raster key art，只出现英文 `SEVENTH DOCK`；标题在上方 25%，底部 20% 不放关键主体。

## 7. UI 与图标

- 使用同一套 1.75 px 线性 SVG：World、人物、地图、背包、日志、关闭、编辑、继续、图片、重试、声音开启与静音。声音控件为页眉中的 44×44 px 图标按钮，与 `Aa` 同级；形状与 `aria-pressed` 同时表达状态。
- 潮位与警戒使用 3 px 状态轨并显示精确读数；补给显示当前值/上限。
- 检定展示技能、DC、骰点、修正、总值与 PASS/MISS；变化批注紧邻原因。
- 人物页顶部为 48 px 主角头像、单行用户名和 You；下方才是 Mira、Oren、Sai。

## 8. 动效与特效

- 输入反馈 90 ms，消息入列 160 ms，抽屉 220 ms，检定落点 420 ms，图片显影 720 ms，数值轨更新 240 ms。
- 阅读位置以文字事件为锚点：开场先露出背景，行动后先露出结果；图片等待态与显影只在原位变化，不触发滚动。
- 流式文字连续增量，不逐字抖动。减少动态时取消位移与扫描，仅保留即时状态和淡入。
- 港风、潮声和低频音乐保持在文字之后；音乐按 8 拍形成和声周期，紧张度从下一拍起改变脉冲密度，连续环境声不重启。静音在 120 ms 内淡出，页面进入后台时暂停音频调度。

## 9. 参考转译

- 旅行日志：连续记录探索痕迹，但不复制真实古董 UI。
- 现场通讯：地点、时间、事实和人物声音清楚分层。
- 活页索引：World 工具随时可取，但不抢占主画面。

## 10. 反模式

- 禁止五轮计数、常驻多面板、每句话掷骰、每回合生图。
- 禁止把叙述、系统记录和数值都做成同一种气泡。
- 禁止固定陌生人替代用户主角；禁止把默认 `U` 当真人参考；禁止保存头像 URL。
- 禁止中文或中英混排正式海报；禁止 UI 截图、SVG/Canvas 栅格化海报。
- 禁止用整页 transform 缩放普通 DOM UI。

## 11. 垂直切片验收

- 单一 Seventh Dock 入口，无 Cartridge 选择器；一次行动、检定、数值变化、内联图片、World 抽屉和章节摘要可玩。
- 390×844 与 320×568 下最新回复、玩家头像、图片、快速回复、输入框和三项数值同时可达，无横向溢出。
- `?avatar_url=<public HTTPS>` 下行动、人物页和生图请求使用同一头像；无头像时 UI 使用默认 `U`，生图退回 txt2img。
- Aigram AI、stateful API 或生图失败时显示原位可恢复状态；剧情接口提供“重试这一步”，不把模板演示或重复文本伪装成正式推进。确定性演示只通过调试参数进入。
- World 摘要行使用同族线性箭头进入详情；详情采用港务档案排版，1:1 方形物品静物图以第七码头封面为美术母图，继承盐渍帆布、旧黄铜、深青搪瓷、锈色灯光和同样的编辑插画笔触，不出现人物或文字。第一次开包时以“潮痕正在显影”和细进度光带解释后台绘制，首图完成后说明自动退场。
